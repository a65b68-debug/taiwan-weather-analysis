# 🌦️ 台灣天氣資料分析系統

## 📌 專案介紹

本專案使用 Python 進行台灣天氣資料分析，透過溫度與降雨量資料，計算平均溫度、最高溫度、最低溫度、累積雨量及最大單日雨量，並使用 Matplotlib 將資料轉換為視覺化圖表。

本專案將持續加入更多氣象資料與分析功能。

---

## 🔍 分析功能

- 🌡️ 7 天溫度資料分析
- 📊 平均溫度計算
- 🔺 最高溫度分析
- 🔻 最低溫度分析
- 🌧️ 7 天降雨量分析
- 💧 累積雨量計算
- ☔ 最大單日雨量分析
- 📈 溫度變化趨勢圖
- 📊 每日降雨量長條圖

### 💻 V4 Python 程式

程式檔案：

`weather_api_analysis.py`

本程式利用 Python Requests 套件向中央氣象署 Open Data API 發送資料請求，
取得 JSON 格式氣象資料後，擷取臺北測站之溫度、相對濕度、風速與觀測時間，
再利用 Matplotlib 將即時資料轉換為視覺化成果。

### 🔐 API Key 安全設計

為避免中央氣象署 API 授權碼公開於 GitHub，
本專案公開版本不儲存個人 API Key，
實際執行時需由使用者自行設定授權碼。

### 四、專題學習反思

在製作「互動式智慧氣象查詢系統」的過程中，我逐漸體會到，程式設計不只是寫出可以執行的程式碼，更重要的是如何運用資訊技術，將生活中常見的問題轉化為具有實用價值的功能。

**一、從生活觀察出發，培養自主學習能力**

天氣資訊與日常生活息息相關，因此我選擇以氣象資料分析作為 Python 專題主題。從初期的溫度與降雨資料分析，到後續結合中央氣象署 Open Data API 的即時氣象查詢，我開始了解如何運用公開資料，讓程式不只是呈現固定數字，而是能處理實際的氣象資訊。

**二、從資料取得到視覺化，建立系統整合觀念**

在專題開發過程中，我接觸 Python 程式設計、API 資料串接、JSON 資料格式及 Matplotlib 圖表呈現等技術，也了解資料取得後，還需要經過整理、分析與視覺化，才能轉換成容易理解的資訊。

從 V5 的多城市氣象比較，到 V8 整合氣象資訊卡片、城市溫度、濕度、風速比較及智慧氣象分析儀表板，我認識到一個完整的資訊系統，需要兼顧資料處理、功能設計與使用者閱讀體驗。

**三、理解程式除錯與資訊安全的重要性**

這項專題也讓我認識到，API 授權、網路連線、資料格式及程式執行環境，都可能影響系統能否正常運作。遇到問題時，不能只依賴反覆執行程式，而應學習閱讀錯誤訊息、確認資料來源及逐步檢查程式邏輯。

此外，我也了解到 API Key 不應直接公開於 GitHub，必須妥善管理存取憑證。這讓我明白，程式開發除了功能實現，也需要重視資訊安全與維護管理。

**四、從完成作品到持續優化，確立未來學習方向**

透過這次專題，我更加理解資訊技術能夠如何結合真實資料，協助使用者快速掌握資訊。我希望未來持續加強 Python、資料分析、人工智慧及系統開發能力，進一步研究如何運用 AI 進行氣象趨勢分析、異常資料辨識及個人化資訊推薦。

這次專題讓我最大的收穫，是開始以系統化的方式思考問題：從需求發想、資料取得、程式處理，到成果呈現與功能改善，每個環節都需要不斷學習與調整。
